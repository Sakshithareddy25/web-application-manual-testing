Test Plan
1. Test Plan Overview

Project: Web Application Manual Testing
Application: SauceDemo
Test Type: Manual Functional Testing
Browser: Google Chrome
Testing Approach: Functional, Negative, Regression, Integration, and End-to-End Testing

2. Objective

The objective of this test plan is to verify the core functionality of the SauceDemo web application and identify defects that could affect user experience or business transactions.

Testing will cover authentication, product browsing, shopping cart operations, checkout, order completion, and application navigation.

3. Scope
In Scope
User login and logout
Login validation and negative scenarios
Product listing and product details
Add and remove products from cart
Multiple product handling
Empty cart behavior
Checkout information validation
Order summary
Order total calculation
Order completion
Navigation between application pages
Out of Scope
Performance testing
Security testing
Accessibility testing
Cross-browser compatibility testing
Mobile application testing
Backend/API testing
Load and stress testing
4. Test Approach

Testing will use a combination of:

Positive testing
Negative testing
Boundary and validation testing
Functional testing
Regression testing
End-to-end testing
Exploratory testing
Integration testing of related user workflows

Test cases will be executed manually and results will be recorded as PASS or FAIL.

7. Entry Criteria

Testing can begin when:

The application is accessible.
Required test credentials are available.
Test scenarios and test cases are prepared.
The test environment is available.
8. Exit Criteria

Testing will be considered complete when:

All planned test cases have been executed.
Failed test cases have been investigated.
Identified defects have been documented.
Test execution results have been recorded.
A final test summary is available.

10. Risks

Potential testing risks include:

Application behavior may change during testing.
Test data may become unavailable.
Environment or browser issues may affect execution.
Some defects may require additional investigation.
11. Deliverables

The following testing deliverables will be maintained:

Requirements document
Test plan
Test scenarios
Test cases
Test execution results
Defect reports
Final test summary
12. Test Completion

A total of 30 test cases are planned for this project. Test execution results and identified defects will be documented after execution.

The final test result will be used to evaluate the functional quality of the application and demonstrate the complete manual QA testing lifecycle.
